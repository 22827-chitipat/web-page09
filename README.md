## ฟีเจอร์

- หน้า Intro พร้อมเอฟเฟกต์ซูมเข้าเว็บ
- Single Page App — สลับ 6 หน้าโดยไม่โหลดใหม่
- ไทม์ไลน์การศึกษา ป.1–ป.6 → ม.3
- การ์ดนักเตะแมนยู 2008 แบบกดดูรายละเอียด
- มินิเกมคิดเลขเร็ว + ดวลจุดโทษ
- เสียงเอฟเฟกต์สร้างจาก Web Audio API (เปิด/ปิดได้)
- พื้นหลังอนุภาคเคลื่อนไหวบน Canvas

## เทคโนโลยี

Tailwind CSS (CDN) • Font Awesome 6 • Google Fonts (Kanit, Space Grotesk) • Vanilla JavaScript
ไม่มี backend และไม่ต้อง build เปิดไฟล์ในเบราว์เซอร์ได้เลย

## วิธีเปิดใช้งาน GitHub Pages

1. Settings → Pages
2. Source: **Deploy from a branch**
3. Branch: **main** / **(root)** → Save
4. รอ 1–3 นาที แล้วเปิดลิงก์ที่ปรากฏ

## เปิดดูบนเครื่องตัวเอง

ดับเบิลคลิก `index.html` ได้เลย (ต้องมีไฟล์รูปอยู่ในโฟลเดอร์เดียวกัน)
